# CrystalLog

蛋白结晶数据管理平台。支持上传试剂盒 Excel 自动解析孔号→条件，记录晶体实验数据与照片，课题组多人协作。

## 技术栈

- **后端**: Node.js + Express + SQLite (sql.js)
- **前端**: React + Vite + Tailwind CSS
- **认证**: JWT + bcryptjs
- **部署**: PM2 + Nginx

## 快速部署

```bash
bash deploy.sh
```
